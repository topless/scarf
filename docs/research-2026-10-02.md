## Football fixtures

| Source | Works? | Notes |
|---|---|---|
| UEFA match API `match.uefa.com/v5/matches?teamId=49&fromDate=…&toDate=…&limit=50&offset=0&order=ASC` | Yes, keyless | Richest: UTC kickoff, stadium, city, address, coordinates. Covers Nations League, qualifiers and friendlies. Undocumented. UEFA terms (section 6.2) explicitly prohibit automated collection and building a database. |
| FIFA calendar API `api.fifa.com/api/v3/calendar/matches?idTeam=43949&from=…&to=…&language=en&count=100` | Yes, keyless | Same fixtures and times, includes friendlies, worldwide teams, open CORS. Messier venue naming, no coordinates. Terms milder than UEFA's but still private, non-commercial use. |
| ESPN `site.api.espn.com/apis/site/v2/sports/soccer/all/teams/455/schedule?fixture=true` | Yes, keyless | Kickoff, venue, city. Undocumented. Useful as a cross-check. |
| FotMob ICS `pub.fotmob.com/prod/pub/api/v2/calendar/team/6383.ics` | Yes | Ready-made subscribable calendar with venue. No TV or tickets. Terms forbid automated reuse, so only usable as a link people subscribe to directly. |
| Wikipedia (MediaWiki API) | Yes | Only clearly permissive licence (CC BY-SA). Hand-edited templates with several spelling variants, so brittle to parse. |
| football-data.org | No | National-team competitions are paid tier. |
| TheSportsDB free tier | No | One next event per team; TV endpoint returned only Qatar and Albania channels. |
| API-Football | Untested | Needs a signup key. |
| openfootball, Wikidata, fixtur.es, epo.gr | No | Missing fixtures, venues or both. |

## TV channels

No free source reliably gives the Greek channel per game ahead of time. The rights holder is stable per competition, so a
small hand-maintained table works from the day a fixture is announced.

| Competition | Greece | Confidence |
|---|---|---|
| Football: Nations League 2026-27 | Alpha (free-to-air) + Novasports | Confirmed for current matches. Euro 2028 qualifiers (2027) on Alpha are likely but unconfirmed; re-check early 2027. |
| Basketball: FIBA qualifiers | ERT (ERT1 or ERT2 Sport, plus ERTFLIX) | Carried recent windows; exact channel varies and contract length is unknown. |

For other viewing countries, `broadcaster.uefa.com/v1/broadcasters?competitionId=2014&countryCode=XX&offset=0&limit=100`
(keyless, undocumented) gives the official football broadcaster per match and shares match ids with the UEFA match API.
It omits Greece's own matches in the Greek-market feed, so it does not replace the table for Greece.
Exact-channel confirmation is only possible in the last 2–7 days (sport-fm.gr/tv, alphatv.gr, ert.gr, an XMLTV feed).

  Home sale for the October games was announced 25 Sep, opened 28 Sep and sold out within hours. Away tickets for
  Germany v Greece went on sale about a month ahead. EPO announces sales in plain-HTML news articles on epo.gr.

- No source offers per-game ticket links automatically.

## Delivery

- Static `.ics` per team on GitHub Pages is served with the right content type and works for Apple, Google and Outlook.
- Calendar refresh lag: Outlook about 3 hours (can exceed 24), Google roughly 12–24 hours per secondary sources, Apple user-configurable.
- GitHub Actions schedules can run hours late, and are auto-disabled after 60 days without repository activity in public repos.
  The popular keepalive action has been blocked by GitHub.
- Feed rules: stable UID from the source match id; times in UTC; all-day event while the time is TBC.
- Libraries: `ical-generator` (Node), `icalendar` (Python).
